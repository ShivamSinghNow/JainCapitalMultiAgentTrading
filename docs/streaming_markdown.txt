ORDER BOOK SPEC:
---------------
~~100-350 millisecond latnency end-to-end, averaging ~150
~30-70 messages per second

| Field Name      | Type   | Description                                                                                                                                               |
| --------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time_exchange` | `str`  | ISO 8601 timestamp when the exchange generated this order-book snapshot                                                                                   |
| `time_coinapi`  | `str`  | ISO 8601 timestamp when CoinAPI received the snapshot                                                                                                     |
| `asks`          | `list` | Array of ask levels, each an object with:<br>  • `price` (`float`): ask price<br>  • `size` (`float`): available volume<br>Sorted by **ascending** price  |
| `bids`          | `list` | Array of bid levels, each an object with:<br>  • `price` (`float`): bid price<br>  • `size` (`float`): available volume<br>Sorted by **descending** price |
| `symbol_id`     | `str`  | Market symbol in `EXCHANGE_SPOT_BASE_QUOTE` format (e.g. `COINBASE_SPOT_BTC_USD`)                                                                         |
| `sequence`      | `int`  | Monotonically increasing sequence number for maintaining update order                                                                                     |
| `type`          | `str`  | Message type, always `"book5"` for top-5 order-book updates                                                                                               |
| `time_ingested` | `str`  | ISO 8601 timestamp when your application ingested this message (e.g. from WebSocket to Redpanda)                                                          |


TICK SPEC:
---------
~~100-350 millisecond latnency end-to-end
1 message per second

| Field Name          | Type    | Description                                                                        |
| ------------------- | ------- | ---------------------------------------------------------------------------------- |
| `period_id`         | `str`   | Duration of the OHLCV interval (e.g., `"1SEC"`, `"1MIN"`, `"1DAY"`)                |
| `time_period_start` | `str`   | ISO 8601 timestamp marking the start of the period                                 |
| `time_period_end`   | `str`   | ISO 8601 timestamp marking the end of the period                                   |
| `time_open`         | `str`   | ISO 8601 timestamp of the first trade in the period                                |
| `time_close`        | `str`   | ISO 8601 timestamp of the last trade in the period                                 |
| `price_open`        | `float` | Price of the first trade in the period                                             |
| `price_high`        | `float` | Highest trade price during the period                                              |
| `price_low`         | `float` | Lowest trade price during the period                                               |
| `price_close`       | `float` | Price of the last trade in the period                                              |
| `volume_traded`     | `float` | Total volume traded during the period                                              |
| `trades_count`      | `int`   | Number of trades that occurred during the period                                   |
| `symbol_id`         | `str`   | Market symbol in `EXCHANGE_SPOT_BASE_QUOTE` format (e.g. `COINBASE_SPOT_BTC_USDT`) |
| `sequence`          | `int`   | Sequence number for maintaining message order                                      |
| `type`              | `str`   | Always `"ohlcv"` for this message type                                             |
